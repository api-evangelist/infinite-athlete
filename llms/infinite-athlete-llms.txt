# Infinite Athlete

> Infinite Athlete is a sports technology company combining performance biomechanics and real-time video to deliver data-driven insights for elite athlete evaluation, development, health, and safety. Its developer product is FusionFeed, a sports and performance data API (REST, GraphQL, and the proprietary FQL) built on the Tempus Ex platform. The developer platform is invite-only. Backed by a16z.

## APIs

- [FusionFeed documentation](https://docs.tempus-ex.com/fusionfeed): Sports and performance data API — schedules, rosters, official/automated stats, telemetry, video feeds, virtual camera. Base URL https://feed.fusion.tempus-ex.com/v2/
- [REST Explorer and Reference](https://docs.tempus-ex.com/fusionfeed/rest/explorer-and-reference): REST interface reference.
- [GraphQL Explorer and Reference](https://docs.tempus-ex.com/fusionfeed/graphql/explorer-and-reference): GraphQL interface reference.
- [Authentication](https://docs.tempus-ex.com/fusionfeed/authentication): API key (Authorization: token), JWT bearer, and OAuth2 via Okta (Authorization Code + PKCE) or Amazon Cognito.
- [Limits](https://docs.tempus-ex.com/fusionfeed/limits): Rate limiting signaled via the txm-limit-consumption header; HTTP 429 on exceed; use exponential backoff.
